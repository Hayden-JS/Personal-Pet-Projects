# Personal Pet Projects (PPP-Projects)

Small browser projects, hosted on GitHub Pages. Each project lives in its own folder.

| Project | Folder | Notes |
|---|---|---|
| Snake: CRT Edition | `snake/` | Retro Snake, 1P solo and 2P co-op, keyboard and touch |

## Adding a project

1. Create a new folder with an `index.html` inside it.
2. Add a card for it on the root `index.html`.
3. Commit and push. Pages rebuilds in a minute or two.
